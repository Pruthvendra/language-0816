# The Zen of 0816

**Version: 0.1**  
**Status: Draft**  
**Date: August 3, 2026**

&gt; *21 principles for every contributor, compiler engineer, and language designer.*

1. **Readable beats clever.**  
   Code is read 10× more than written. In the AI era, it is audited 100× more.

2. **Trust beats speed.**  
   A fast compiler that generates untrustworthy code is a liability.

3. **Correctness beats convenience.**  
   "Almost right" AI-generated code is the most dangerous kind.

4. **Consistency beats creativity.**  
   One obvious solution is enough.

5. **Simple solutions age better.**  
   What is simple in 2026 will still be simple in 2036.

6. **Architecture before implementation.**  
   Design the idea. Then write the code.

7. **Security is default.**  
   Secure by design. Insecure only by explicit, documented intent.

8. **Documentation is engineering.**  
   If it is not documented, it is not finished.

9. **AI assists. Humans decide.**  
   Every important decision must remain explainable by a human.

10. **Small improvements compound.**  
    A 1% better error message today prevents 100 hours of debugging tomorrow.

11. **Every feature has a cost.**  
    The cost is cognitive load, documentation, and trust.

12. **Remove before adding.**  
    The best code is the code you did not write.

13. **Stable software earns trust.**  
    Breaking changes break trust.

14. **Explain before optimizing.**  
    If you cannot explain why it is slow, you cannot explain why the optimization is safe.

15. **Code should communicate intent.**  
    A developer should understand not just what, but why.

16. **One obvious solution is enough.**  
    There should be one — and preferably only one — obvious way to do it.

17. **Backward compatibility matters.**  
    What works today must work tomorrow.

18. **Think globally. Build incrementally.**  
    The vision is 20 years. The next commit is today.

19. **Engineer patiently.**  
    Hype is temporary. Correctness is permanent.

20. **Trust is earned.**  
    Through consistent behavior, predictable releases, and transparent governance.

21. **If AI wrote it, a human must still own it.**  
    Generated code is a suggestion. Committed code is a promise.

---

&gt; *"Great software is written twice: first in thoughtful documents, then in code."*
