# Foundation Charter

**Project 0816**  
**Version: 0.1**  
**Status: Draft**  
**Last Reviewed: August 2026**

---

## Mission

Project 0816 exists to define the programming language for the AI Engineering Era.

## Vision

A programming language designed from day one for the AI Engineering Era.

## The Language

**Harven** is the programming language developed under Project 0816.

## Founding Principle

Build software that people trust.

Everything else is secondary.

---

## Immutable Principles

1. **Trust is the primary optimization target.**
2. **AI assists. Humans decide.** No autonomous AI commits.
3. **Security is default.** Insecure only by explicit, documented intent.
4. **Documentation leads implementation.**
5. **Backward compatibility is a promise.**
6. **We build for decades.** Every decision answers: "Will this still make sense in 2035?"

---

## Governance

- **Founder:** Final authority on mission and direction.
- **Chief Architect:** Vision, language design, trust model, long-term consistency.
- **Engineering Partner:** Repository management, implementation review, operations.

## Amendment Process

This charter may only be amended if:
1. The change is proposed via a formal Issue.
2. The rationale addresses why the current text fails.
3. The change is reviewed against all six immutable principles.
4. The Founder and Chief Architect approve.
